## 🛠️ Stack Tecnológica Rápida

- **Frontend**: React 18 + TypeScript + Vite
- **Estilização**: Tailwind CSS 4 + Framer Motion
- **3D**: Three.js + React Three Fiber (R3F)
- **Qualidade**: Biome (Lint/Format) + Jest (Testes)
